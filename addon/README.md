# Spicy Lyrics для Яндекс Музыки

Тексты песен в стиле [Spicy Lyrics](https://github.com/Spikerko/spicy-lyrics): пословная синхронизация с заливкой и пружинной анимацией, свечение букв на длинных слогах, точки в паузах, бэк-вокал и дуэты, динамический фон из обложки и NowBar.

## Как открыть

- Кнопка **Spicy Lyrics** в плеер-баре.
- Родная кнопка текста Яндекс Музыки и пункт «Показать текст» в меню трека тоже открывают Spicy Lyrics (можно отключить в настройках). Родная кнопка активна только для треков, у которых в Яндекс Музыке есть синхронизированный текст, — для остальных используйте кнопку Spicy Lyrics.
- Клик по строке перематывает трек к ней.
- Кнопки вида справа сверху: кинорежим на всё окно (с управлением плеером и громкостью на обложке), NowBar, смена его стороны, закрыть. `Esc` выходит из полноэкранного режима или закрывает вид.

## Источники текста

1. **Spicy Lyrics API** — библиотека Spicy Lyrics (тексты сообщества, Apple Music, Spotify) с пословной синхронизацией. Работает сразу после установки, ничего настраивать не нужно: у аддона есть свой ключ. Если встроенный упрётся в лимиты, можно указать в настройках свой публичный ключ (`sl_pk_…`) с [developers.spicylyrics.org](https://developers.spicylyrics.org) — в его Allowed origins должно быть значение `null`.
2. **Яндекс Музыка** — родной синхронизированный или обычный текст. Яндекс отдаёт тексты не во всех странах: если трафик идёт через VPN или прокси с зарубежным IP, текстов у него нет совсем, и аддон берёт их из Spicy и LRCLIB. Чтобы вернуть тексты Яндекса, пустите Яндекс Музыку мимо VPN.
3. **LRCLIB** — открытая база текстов, иногда с пословной синхронизацией. Когда LRCLIB перегружен («server busy»), аддон повторяет запрос; если у Яндекса синхронного текста нет, ждёт до 20 секунд.

Трек в библиотеке Spicy ищется по Spotify ID. Аддон находит его сам, без ключей, тем же поиском Spotify, что и официальное приложение Spicy Lyrics Mobile, а также в справочнике ListenBrainz. Свои Spotify Client ID и Secret можно указать в настройках: тогда поиск идёт через официальный Spotify Web API. Для подкастов, аудиокниг и загруженных вами треков используются только Яндекс Музыка и LRCLIB.

Найденные тексты кэшируются на 3 дня (последние 40 треков), поэтому повторное открытие мгновенное.

## Настройки

- **Источники:** свой ключ Spicy (необязательно), Spotify Client ID/Secret, порядок («лучший» или «сначала Яндекс»), включение каждого источника.
- **Вид:** простой режим (без пословной анимации), размытие строк, подсветка строки при наведении, фон (динамический, обложка, цвет обложки, без фона), шрифт Spicy.
- **Синхронизация:** сдвиг тайминга от −2000 до +2000 мс, если текст спешит или отстаёт.
- **Родная кнопка:** заменить ли кнопку текста Яндекс Музыки.

Все изменения применяются сразу, без перезапуска.
